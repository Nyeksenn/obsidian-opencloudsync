# Third-party notices

`main.js`, the file this plugin ships, contains code from the packages below. Their licenses require that the
copyright notices and permission texts travel with every copy, so this file is reproduced in full at the top of
`main.js` by the build (`esbuild.config.mjs`). Tests and development tools are not distributed and are not
listed. A unit test (`tests/a-no-nextcloud/opencloud/thirdPartyNotices.test.ts`) fails when the bundle gains a
package that is not listed here.

| Component | Version | License | Where it comes from |
|---|---|---|---|
| reconcile-text | 0.13.2 | MIT | npm dependency (text merging); Rust compiled to WebAssembly |
| node-diff3 | 3.2.1 | MIT | npm dependency (three-way diff) |
| semver | 7.8.5 | ISC | npm dependency (version comparison) |
| wasm-bindgen, serde, thiserror, console_error_panic_hook | as built into reconcile-text 0.13.2 | MIT OR Apache-2.0, used under MIT | Rust crates compiled into reconcile-text |
| Rust standard library | as built into reconcile-text 0.13.2 | MIT OR Apache-2.0, used under MIT | compiled into reconcile-text |

The Rust components are dual-licensed; this distribution uses them under the MIT license. Which of the optional
crates (`serde`, `wasm-bindgen`, `console_error_panic_hook`) are linked depends on how reconcile-text's npm build was
compiled; all are listed so that none is missing.
